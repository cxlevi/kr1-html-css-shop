# TechStore — интернет-магазин электроники

## Описание
Многостраничный сайт интернет-магазина электроники TechStore. Проект выполнен в рамках контрольной работы №1 по веб-разработке.

## Технологии
- HTML5 (семантическая разметка)
- CSS3 (Flexbox, Grid, переменные, БЭМ)
- Минимум JavaScript (только для модального окна)

## Структура проекта
style.css # Единый файл стилей для всех страниц
main.js # Скрипт для модального окна
index.html # Главная страница
catalog.html # Каталог товаров
product.html # Страница товара
order.html # Оформление заказа
contacts.html # Контакты
README.md # Этот файл

## Страницы
- **Главная** (`index.html`) — hero-блок, преимущества, популярные товары
- **Каталог** (`catalog.html`) — сетка товаров с фильтрами
- **Товар** (`product.html`) — подробная информация и таблица характеристик
- **Заказ** (`order.html`) — форма оформления заявки
- **Контакты** (`contacts.html`) — контактная информация и форма обратной связи

## Доработки сверх минимума
- Адаптивная вёрстка (медиа-запросы для мобильных устройств)
- Hover-эффекты на карточках и кнопках
- Плавная прокрутка к якорям
- Закрытие модального окна по клавише Esc и клику на оверлей
- Встроенная карта на странице контактов
